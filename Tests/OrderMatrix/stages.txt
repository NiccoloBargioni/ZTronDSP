# The public stages of the package, one per line: `Type | an expression that makes one`.
#
# Scripts/order-matrix.sh type-checks each expression after a pipeline that ends in each domain
# of domains.txt (ORD-2). Any valid arguments will do: what is asked is where the stage may
# stand, not what it computes. A package that adds a stage adds its line here (STG-1); a public
# stage of the API digests without a line here, or in not-in-matrix.txt with the reason it is
# not in the matrix, fails the check. A second spelling of a stage (its measuring one, say) gets
# a line named `Type: what is different`.
