## What

§4.2 lists `ZTronDSPTesting` as one target in Swift and C. The package declares two: `ZTronDSPTesting` (Swift) and
`CZTronDSPTesting` (C: the `malloc_logger` probe and the floating-point environment digest). The product
`ZTronDSPTesting` contains both. `Scripts/check-dependency-graph.sh` treats the pair as the one target of §4.2.

## Why

A SwiftPM target holds one language; a C hook cannot live in a Swift target.

## Evidence

SwiftPM rejects a target with both `.swift` and `.c` sources. The graph check passes with the pair read as one target.
