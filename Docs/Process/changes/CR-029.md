## What

1. **`.up` and the rounded figure.** §6.3.4 says "`.up` guarantees at least the requested slope" and, in the same section, gives one order as "6.0206 dB per octave". The exact figure is 20·log₁₀2 = 6.020599913…, so 6.0206 dB per octave is 8.7·10⁻⁸ dB *more* than one order, and the literal rule makes it order 2. The code therefore takes a slope within one part in a million of a whole order as that order, and can return up to 1 ppm less slope than was asked for. **Proposed wording:** "`.up` gives the smallest whole order whose slope is at least the one requested; a slope within 10⁻⁶ relative of a whole order is that order, so that the rounded figure 6.0206 dB per octave is order 1." The other reading, the owner's to choose instead: `.up` without the slack, and 6.0206 dB per octave is order 2 under `.up` (it stays order 1 under `.exact` and `.nearest`).
2. **`BiquadPrecision` is a closed enum** (`.single`, `.double`, `.automatic`). §5.3 puts every strategy behind a public protocol so that "a conformer written outside the package is passed the same way". A precision selects one of the package's own C kernels: there is nothing a conformer outside the package could add that the engine could run. `ConvolutionStrategy` is an enum for the same reason (CR-023 item 8). **`RollOffRounding`, which §5.3 lists too and which is an enum today, is not covered by this item:** a rounding rule can be written outside the package, so it becomes a public protocol with the three stock values, in the fix cycle of WP-103.

## Why

Item 1: the specification contradicts itself at the one figure it prints. Item 2: public API differs from §5.3 (blocking by §11.6 unless a change request says so).

## Evidence

Item 1: `Docs/Process/reports/WP-103-A.md` (A-7): 6.0206 dB per octave gives order 1 = 6.020599913 dB per octave, 8.7·10⁻⁸ dB short; of 64 slopes 0.5 ppm above a whole order, all 64 get an order whose slope is below the request. Item 2: `Sources/ZTronDSPCore/Toolkit/Implementation.swift:19`, `Sources/ZTronDSPCore/Units/RollOff.swift:4`; the audit `audit-m4a-B.md`, gap G-1.
