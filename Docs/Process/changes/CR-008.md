## What

`Group` is also a SwiftUI type (and so are `Window` and `Section`, which later packages deliver). The names of the
specification are kept. `PipelineBuilder` gains `buildExpression(_:)` over stage values, which makes each line of a
block resolve as a stage before it is composed, so `Group { … }` inside a pipeline block compiles in a file that
imports SwiftUI. Where the compiler still cannot tell (a group built on its own and then given `.environment`), the
documentation says to write `ZTronDSP.Group`.

## Why

The examples of §5.9 build pipelines inside SwiftUI views, where both modules are imported. Without the change a
one-line `Group { Stage() }` in a pipeline block failed to compile there with a message that named neither `Group`.

## Evidence

Probe, Swift 6.4, with `import SwiftUI` and `import ZTronDSPCore`: `Pipeline { A(); Group { B() } }` failed with
"cannot convert value of type 'Group<B>' to expected argument type 'Emit<Sink>'"; with `buildExpression` it compiles,
as do the multi-line, switched and nested forms, with and without SwiftUI imported.
