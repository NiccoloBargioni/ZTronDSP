## What

WP-110b lists `ScalarFrame` among the borrowed views with index and time. It is a plain `Hashable`, `Sendable` value of
`value` and `confidence` (§5.2). The index and the time of a scalar frame are those of the `FrameView` that carries it.

## Why

`Binding<ScalarFrame>` is a sink (§5.10), and OUT-3 writes a binding only when the value changed. A frame that carried
its index would never compare equal to the last one, and every heartbeat would invalidate the view.

## Evidence

`FrameTests.scalarFramesCarryAValueAndAConfidence`.

§5.2, WP-110b.
