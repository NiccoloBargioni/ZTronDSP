The function neither throws nor documents a limit on the factor. By reading only (not run): `:6` is the first overflow on that path, and `index += factor` (`:13`) overflows the same way once a kept index plus the factor passes `Int.max`; `upsampled` forms `samples.count * factor` (`:24`), which overflows for a factor above `Int.max / count`. Reproduce: [T] `VerifierA/run-each.sh t VerifierA_WP117_Trap` after a probe build. Resolve: wrap without overflow (`let r = phase % factor; r < 0 ? r + factor : r`), stop the loop before the index would pass `samples.count` without adding past `Int.max`, and state or check the largest factor `upsampled` takes. | blocking |
