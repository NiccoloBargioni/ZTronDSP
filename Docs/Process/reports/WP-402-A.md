**A-4 in full.**

κ is `inf` in each of these cases:

- The double root of x² − 2x + 1.
- An overflowing weighted sum (coefficients of 10³⁰⁰ at 10¹⁰).
- `CompanionQRRootFinder().rootConditions(of: x² − x + 1/4)`, which gives [inf, inf].
- `TransferFunction(numerator: [1], denominator: [1, −1, 0.25], domain: .digital).poleConditions`, which gives [inf, inf].

For the same situation the package states a finite result elsewhere: K(1) (`EllipticFunctions.swift:52`) and the response at a pole (`LTISystem.swift:62`, `:203`) are `greatestFiniteMagnitude`. No change request exempts κ. (The same `.infinity` convention is used in `SystemAnalysis.swift:238` and `:487`, `roundOffNoiseGain`, which belongs to WP-428b and is not in this batch).

**A-4, to reproduce or resolve.** `VerifierA/scripts/run-repro.sh 2`: `a4ConditionNumbersAreFinite` fails four expectations. Resolve by returning `greatestFiniteMagnitude`, the package's convention, documented as the condition of a multiple root. Otherwise, file a change request that makes ∞ a stated exception to NUM-1.
