## Lens checklist (§11.5)

- **A — API, architecture, platform.**

- Shape: `feed.snapshot() -> FeedSnapshot`, a `Sendable`, `Hashable` struct of `let`s (content, axis, environment, row count, values column after column, times), with `column(_:)`, `row(_:)`, `minima`, `maxima` and `pyramid()`. No configuration object, no setter.
- Threading: `snapshot()` takes the readers' lock and allocates the copy, so it is for any thread but the analysis thread, as the feed's comment says; nothing enforces that. BG-1 concerns `FeedSnapshot.image`, which belongs to a later package.
