## Lens checklist (§11.5)

- **N — numerical correctness.**
  - Definition (RT-6): a state value whose magnitude is below 10⁻²⁰ becomes zero. Checked value by value with exact rational arithmetic for both precisions: correct for subnormal values, the smallest normal, ±10⁻²¹, −0 (becomes +0) and for everything from 10⁻¹⁹ up; NaN and the infinities are left as they are (NUM-1 keeps them out). One representable value per sign and precision is on the wrong side (finding 1).
  - Edge cases: a count of 0 (in the audit test), length 1, silence, full scale, subnormal input, non-finite values: as above.
  - The history kernels' variant (a sample below the floor enters as zero) checked on the FIR against `numpy.convolve` of the cleaned input: largest difference 1.6·10⁻⁷, no subnormal output.
  - The tests fail when the flush is broken: with `state[i] = value` in place of `= 0.0f` (ztd_support.c:10) `valuesBelowTheFloorBecomeZero`, `aDecayingTailReachesExactZeroWithinOneBlockOfFallingBelowTheFloor`, `flushingIsAllocationFree` and the tail and subnormal-input tests of the biquad, FIR, decimator, interpolator and partitioned suites fail.
  - No tolerance was found loosened in this package's own tests. Not tagged `ALG`: no currency record or stability note is due.
