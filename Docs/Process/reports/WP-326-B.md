## Lens checklist (§11.5)

- **N — numerical correctness.**
  - The main line with taps equals the main line without them, bit for bit. Edge cases run by the verifier: empty input (empty output), one sample, silence, full-scale Nyquist (±1 alternating), full-scale DC, an impulse, noise, denormals, and non-finite input (NaN, +∞, −∞ become 0 where the signal enters, identically with and without taps; every output sample is finite). Block sizes 1, 7, 64, 512; mono and stereo.
  - A branch never writes the buffer it reads: a kernel run writes into its own output, a processor works on a copy, a switched region keeps its own history.
  - Fusion does not cross a tap point; the unfused kernels give the bits of the fused ones (F1 by CR-006, F2).
  - Precision: Float32 samples throughout; nothing to choose in this package. No tolerance is involved: every comparison is exact.
