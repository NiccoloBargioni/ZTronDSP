## Findings (VER-4)

| 2 | §9.3, no trap from invalid input | `AudioBuffer.init` (WP-104), reached from `Engine/OfflineRunner.swift:36` | `Pipeline().process([0, 0], format: SignalFormat(sampleRate: 48_000), blockSize: Int.max)` ends the process (arithmetic overflow, crash report `xctest-2026-11-15-184058.ips`); `blockSize >= 1` is the only check. | non-blocking |

**Finding 1, to reproduce or resolve.** Probe (the same in Debug and Release):

```swift
let signal = TestSignal.whiteNoise(count: 2_000, seed: 9), format = SignalFormat(sampleRate: 48_000)
let off = StateBox(false)
let pipeline = Pipeline { TestGain(0.5, isActive: off.binding) }
let sink = CollectingSink<Samples>()
let session = try await DSPEngine(blockSize: 64).attach(pipeline.emit(to: sink), to: BufferSource(signal, sampleRate: 48_000))
try session.start(); _ = await session.reaches(.finished)              // sink.samples == signal: the stage is bypassed
let offMain = try await Task.detached { try pipeline.process(signal, format: format, blockSize: 64) }.value
#expect(offMain == sink.samples)     // fails: offMain[0] == 0.18236274, sink.samples[0] == 0.36472547
```

Called on the main actor the same call equals the engine. Cause: `OfflineRunner.swift:31-34`, "Off it, a bound switch
counts as on"; bound results are likewise delivered only on the main thread (`OfflineRunner.swift:117-121`). The rule is in
the documentation comment of `process` and in no change request. To resolve: a change request that states it, or a typed
error for a pipeline with bound switches processed off the main actor.
