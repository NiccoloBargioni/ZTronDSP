## Lens checklist (§11.5)

- **A — API, architecture, platform.**
  - OUT-2: `ResultSlot` is the latest-value slot: one atomic word for a scalar, a sequence counter around a pre-allocated vector; written wait-free on the analysis thread, read on the main thread. The heartbeat is a `CFRunLoopTimer` at `resultRate` (clamped to 1…1 000 per second) on the main run loop, common modes, present exactly while the session runs and results are bound.
  - OUT-3: `BoundResult.write` is `@MainActor`; `deliver()` writes a slot's binding at most once per beat and only when the value differs from the last one written (for `Binding<Float>` the value alone, so a change of confidence does not invalidate a view that shows the value).
  - OUT-4: `BoundResult` compares by kind only. OUT-5: `Binding<[Float]>` receives a new array made on the main thread; nothing is written when the session stops.
  - BIND-7 / DEP-1: `Binding` named in `Bindings/` only. No Combine, no `AnyView`, no UIKit (lint clean). The pump is internal.
  - `environment.resultRate` is one of the three settable keys (ENV-3) and is read from the environment at the source.
