## Lens checklist (§11.5)

- **N — numerical correctness.** Both stages equal their offline functions within Float32 rounding, at block sizes 1, 37 or 64, and 512. The Savitzky–Golay stage starts as `.constant(0)` in every mode, as CR-018 item 3 states. Edge cases: block size 1, derivatives, both tracker outputs, and α = 1, β = 0. **The tracker's settling time is not declared, so the output after a re-activation is not the settled output that ACT-7 requires.** No tolerance was loosened.
