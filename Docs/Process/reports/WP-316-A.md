## Lens checklist (§11.5)

- **N — numerical correctness.**

- Definitions checked by reading against the code: the linear and the logarithmic chirp phases and their continuation past the end are the closed forms of the integrals (`GeneratorSource.swift:237-257`); white noise is SplitMix64 mapped to 24 bits in −1 ..< 1, exact in Float; pink noise is Kellet's filter with its published coefficients. Phase is accumulated from the sample index in Double, so there is no drift with the block size.
- Edge cases: 0 Hz and Nyquist are accepted and give sin(phase) and sin(πn + phase); a frequency above Nyquist, a rate of 0, a negative duration, a period of 0 and a chirp of no length are typed errors (tested). A duration of 0 ends the stream at once. A non-finite amplitude or function value reaches the adapter's guard (NUM-1).
- No tolerance looks loosened: the sine is compared exactly, the chirp at 10⁻⁶ of full scale.

**Finding 1, to reproduce or resolve.** Each line ends the process (run one at a time; crash reports name the frames):

```swift
try await GeneratorSource(.silence, duration: 1e16).prepare()
// Fatal error: Double value cannot be converted to Int because the result would be greater than Int.max  (GeneratorSource.swift:146)
_ = GeneratorSource(.silence, channelCount: Int.max / 4)
// Swift runtime failure: arithmetic overflow in GeneratorSource.init                                      (GeneratorSource.swift:127)
```

`duration` is checked to be finite and not negative two lines above the conversion, so a caller who writes a very large
number for "no end" passes the check and traps. To resolve: bound the frame count (`Int(exactly:)`, or clamp to
`Int.max`), and validate the channel count before allocating.
