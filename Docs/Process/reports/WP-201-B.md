## Lens checklist (§11.5)

- **A — API, architecture, platform.**
  - `ZTD_NONBLOCKING` is `__attribute__((nonblocking))` (include/ztd_base.h:17). Every function of the target that can run on the I/O or analysis thread carries it on declaration and definition; what does not carry it is control-context (`…_create`, `…_destroy`, `ztd_plan_append`, `ztd_plan_transfer`, `ztd_ring_reset`, the plan slot's control side) or blocks by design (`ztd_ring_write_waiting`, `ztd_thread_sleep_until`, the thread policy calls). Checked by listing every definition without the attribute.
  - The allow-list is a private header (`Sources/CZTronDSP/ztd_vdsp.h`, not under `include/`): 12 entries, each used by the target, each naming an audit that exists; no vDSP call from non-blocking code is missing from it (a call that is not listed does not build: fixture `UnlistedVDSPNonblocking.c`). Setup creation and destruction are not listed.
  - Manifest: tools 6.2, `.enableWarning("function-effects")`, `.treatWarning("function-effects", as: .error)`, no unsafe flags (E-32). DEP-1: the M2 sources include libc, `<stdatomic.h>`, Mach, pthread and Accelerate only.
  - The nine public headers of this layer compile standing alone as C11 (`-Wall -Wextra -Wpedantic`, function-effect errors on) and as C++17. Availability: every vDSP entry used exists at the 15.0 floor (E-08).
  - API digest: `Scripts/api-digest.sh --check --skip-public-only` against the last Debug build: `CZTronDSP` equals `Docs/API/CZTronDSP.txt` (the one module reported as different is `CZTronDSPTesting`, by the five probe functions the verifier added to its own checkout). `Scripts/lint-bans.sh`: clean. `Scripts/golden.sh --check`: 93 files match.
