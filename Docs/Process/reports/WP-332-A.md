## Lens checklist (§11.5)

- **R — real-time safety and performance.**

- OUT-2: the analysis thread writes a scalar as one atomic word and a vector under a version counter, wait-free, into storage allocated at the claim (`ResultSlot.swift:44-58`); inside the 10⁴-block audit of WP-324 (a bound scalar). The heartbeat is a `CFRunLoopTimer` at the result rate that exists only while the session runs and has bound results (`BindingPump.swift:266-277`).
- OUT-3: `deliver` compares with the last value written since the capture; after a capture (a new topology, a re-plan) the first value is written even when it equals what the binding holds.
- OUT-5: `readVector` allocates the array on the main thread.

**Finding 1, to reproduce or resolve.** Probe (fails in Debug and Release):

```swift
let rig = Rig()
let vector = StateBox([Float]())
let before = Pipeline().tap { $0.testFramer(frame: 64, hop: 64).testMagnitude().emit(to: vector.binding) }
let session = try await rig.engine.attach(before, to: rig.source)
try session.start(); await rig.drain()
rig.feed([Float](repeating: 0.5, count: 64 * 4))
await MainActor.run { session.core.pump.deliver() }                 // vector.value[0] == 0.5·√2
try await session.update(before.testGain(0.5)); await rig.drain()   // the tap is untouched
rig.feed([Float](repeating: 0.5, count: 64 * 16)); await rig.drain()
rig.feed([Float](repeating: 0.25, count: 64 * 8)); await rig.drain()
await MainActor.run { session.core.pump.deliver() }
#expect(abs(vector.value[0] - 0.25 * Float(2).squareRoot()) < 1e-5)  // fails: still 0.70710677, vector.writes == 1
```

A `Binding<Float>` after `TestMean()` in the same tap follows the signal. Cause: every plan makes new `ResultSlot`s
(`ExecutionPlan.swift:84`); a slot whose sink key the previous plan had is not a new branch (`ExecutionPlan.swift:232`), and
`adoptSinks` claims only new branches (`EngineCore.swift:876`); an unclaimed vector slot has no storage and `write` returns at
its guard (`ResultSlot.swift:36-40, 51`). The pump is given the new slots, so nothing arrives any more. To resolve: claim every
result slot of a new plan, or carry the slot of an unchanged branch over; add the probe as a test.
