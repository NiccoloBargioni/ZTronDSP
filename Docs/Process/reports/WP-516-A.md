## Lens checklist (§11.5)

- **N — numerical correctness.**
  - Definition: the stage is the head of `DSP.convolve(x, h, mode: .full)` on the stream (§6.7, "streaming"); `.direct` uses the core's FIR kernel, `.partitioned` and `.fft` the partitioned kernel with the partition equal to the block, `.automatic` the crossover table (SEL-3: the plan's own `.fir`, `:107`; a strategy against the table names the C kernel itself, `:115` and `:118`). Read against `Convolve.swift:93–120`.
  - Precision: `Float` throughout, as the one-shot function; the error on 700 taps is 3.5·10⁻⁷ of the largest output.
  - Tolerance: the tests use 10⁻⁵ of the largest output; not loosened.
  - Edge cases (`out/edge-e05-convolve-stage.txt`; 300 taps; `.direct`, `.fft`, `.partitioned`, `.automatic`):

    | Input | Result |
    |---|---|
    | Empty stream | 0 samples |
    | Length 1 | 1 sample, equal to the one-shot head |
    | DC, Nyquist, silence, full-scale square (1 024 samples) | Equal to the one-shot head (difference 0.0); silence gives zeros |
    | `NaN`, `+∞`, `−∞` samples | Replaced by 0 at the source; equal to the same stream with zeros in their place |
    | `FLT_MAX` DC | `.direct`: 802 finite values and 222 ±∞ where the true sum exceeds the range (CR-VA-1); `.fft`, `.partitioned`, `.automatic`: 1 024 of 1 024 NaN: A-8 |
    | Kernel `[FLT_MAX]` or `[−FLT_MAX]` on noise | Finite, ±1.68·10³⁸ (the truth) |
    | Kernel `[1e-45]` or `[0]` | Signed zeros (RT-6 flushes the subnormal products) |
    | Kernel empty or with a non-finite tap | Refused when attached (`aKernelThatIsNoneIsRefused`) |
    | Rate 5·10⁻³²⁴, 10⁹ Hz, `greatestFiniteMagnitude` | `.fft` and `.partitioned` run; `.automatic` with 3 taps refuses 10¹² Hz and `greatestFiniteMagnitude` with `invalidParameter` ("the 10 ms over which taps are exchanged are not a number of frames a kernel can count") |
