## Lens checklist (§11.5)

- **A — API, architecture, platform.**

- Shapes: `SampleProcessor` is the protocol of §5.11.1 (`latencyFrames`, `settlingFrames`, `process(_ block: inout AudioBlock)`, `reset()`); a stage emits `.processor(CustomProcessor(name:key:latencyFrames:make:))` or `.custom(CustomKernel(name:key:interpolation:decimation:latencyFrames:make:))`. Labelled arguments with defaults, no configuration object (API-6). `ztd_kernel_t.process` returns the frames written (CR-004).
- EXT-2: a processor is wrapped behind the kernel ABI (`ProcessorKernel.swift`), so it is switched, pre-rolled and moved by the same C plan; a custom kernel is a fusion barrier (`fusedAndUnfusedGainsAgreeBitForBit`).
- EXT-1: the test stages use public declarations only; `Scripts/lint-bans.sh` part 3 is clean.
