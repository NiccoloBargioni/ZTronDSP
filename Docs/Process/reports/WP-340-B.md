## Lens checklist (§11.5)

- **R — real-time safety and performance.**
  - RT-1 / RT-2: `ztd_copy_finite` is C, declared `nonblocking`, branch-free (a mask on the exponent bits), works in place, allocates nothing. It runs once per channel per block on the analysis thread, where the block enters, for push and pull sources alike; the count is one atomic add, made only when something was replaced, and the control context is asked for attention only when the count moved.
  - The allocation audit: the 10⁴-block audit of the suite runs through `SourceAdapter.next` with the guard in it (Debug and Release).
  - Cost (Release, indicative): 165 ns per block of 512 frames (0.3 ns per sample) against 22 ns for a `memcpy` of the same block; 0.002 % of the block's duration.
  - No hidden copy: in place.
  - Order of reporting: the event is emitted by the control context's service, before a stream that ended takes its sessions out of what runs (`EngineCore.service`), so a short stream does not lose it.
  - A benchmark is recorded: none.
