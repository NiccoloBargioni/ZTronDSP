## Lens checklist (§11.5)

- **N — numerical correctness.**
  - Definition: r[ℓ] = Σₙ x[n + ℓ]·y[n] (§6.7), the same engine as WP-513 with the conjugate spectrum (`Convolution.swift:170–176`); `.biased` divides by N, `.unbiased` by N − |ℓ|, `.coefficient` by √(Σx²·Σy²), with zeros when that denominator is not above `correlationFloor` (10⁻²⁰) or not finite (`Correlation.swift:75–78`). Read against the code.
  - Precision: `Float` sums, energies in `Double` (`Correlation.swift:167`). Right for the data; the denominators are the only place where precision is short, and `Double` is used there.
  - Tolerance: 10⁻⁵ as the oracle table says; CR-023 item 11 reports the one exception (`.unbiased` by transform at 1.07·10⁻⁵ against the sums, held to the sums). Nothing was loosened.
  - Edge cases (`VAEdges/e02Correlate()`, `out/edge-e02-correlate.txt`; every normalisation, mode and strategy):

    | Input | Result |
