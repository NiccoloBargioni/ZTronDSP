- CR-015 items 6 and 8 describe the code (content times; one engine per source).
- SRC-1 / ATT-2: `ProcessedSource` adopts neither `PushSampleSource` nor `PullSampleSource`; the engine recognises it through `SourceAdapter.processed(_:)` (`SourceAdapter.swift:42-44`), a cast to the concrete type that the lint of ATT-2 does not see because the file is outside `Engine/`, and then branches on `hub.processed` / `hub.inner` (`EngineCore.swift:169, 216, 360, 447`). That is the pattern of push and pull (the adapter tells, the engine uses), applied to a kind only this type can be: a derived source cannot be written outside the package.
