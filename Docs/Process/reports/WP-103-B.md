## Lens checklist (§11.5)

- **A — API, architecture, platform.**
  - Names and shapes (§6.3.4): `RollOff.decibelsPerOctave(_:)`, `.decibelsPerDecade(_:)`, `.order(_:)`, `order(rounding:)` with `RollOffRounding.exact(relativeTolerance: 0.02)`, `.nearest` and `.up`; the constants of one order (20·log₁₀2 dB per octave, 20 dB per decade). The public API equals the committed digest.
  - Immutability, no configuration object: `RollOff` and `RollOffRounding` are immutable values (`Hashable`, `Sendable`); the rounding is an argument.
  - Typed errors: `order(rounding:)` is `throws(DSPError)`; slopes that are no filter (zero, negative, non-finite) and orders above 4 096 are `invalidParameter` (`slopesThatAreNoFilterAreTypedErrors`; a slope of 10³⁰⁰ dB per octave throws, crash probe `rollOffOrderOfIntMax`), except for an order near `Int.max`, which traps (B-1).
  - Concurrency, DEP, platform: Swift 6 language mode; Foundation only; nothing above iOS 15; no UIKit, Combine or `AnyView`.
  - VIS-2: 13 of 16 public declarations documented; the three factories are not (B-18).
