- **R — real-time safety and performance.**
  - **The line changed to confirm the audit.**
    - The change: at `Sources/CZTronDSP/ztd_biquad_double.c:29`, a `malloc(16)`/`free` per call was put into the process function of the double kernel, with a pragma that silences `-Wfunction-effects` for it (`mutate.py apply wp433-alloc`).
    - Two tests then fail at the audit, in Debug (run M2) and in Release (`VerifierB/release-runs.sh`): `StockPipelineAuditTests/tenThousandBlocksOfALiveSessionAllocateNothing()` (`SequenceStageTests.swift:591`) and `theMeasurementRunsOnTheControlContextNotOnTheMainThread()` (`PrecisionTests.swift:157`). Pristine, both pass in both builds.
    - The file was restored and compared byte for byte with the pristine copy: identical.
  - **RT-1.**
    - `process`, `command` and `reset` are `ZTD_NONBLOCKING` (lines 28, 55, 61).
    - `Scripts/check-function-effects.sh --fixtures`: the target's 19 C sources build clean with `-Werror=function-effects`, and a non-blocking function that calls `malloc` does not build.
  - **RT-3 and RT-5, no hidden copies.** A command copies the new coefficients with one `memcpy` from memory the control side prepared (line 58). The state is flushed of subnormals at the end of each block (line 50; RT-6).
  - **Complexity.** O(sections) per sample (lines 37–46), as in §7.2, row 3. The measurement runs each cascade on two signals of 4 096 samples (an impulse and seeded noise) in both precisions, at plan compile only.
  - **Setups at compile; SEL-3.**
    - `PrecisionMeasurement` (`Realization.swift:98–196`) creates the kernel the plan would create: `vDSP_biquadm` from three channels, otherwise the C loop or `vDSP_biquad`, by the implementation the context selects for the block size.     - `theMeasurementIsThatOfTheKernelThePlanCreates()`, for a 1 kHz high-pass of order 4: vDSP −99.13 dB, C loop −111.14 dB, `vDSP_biquadm` −115.86 dB. Equal input gives an equal figure.
  - **REAL-3.** An update that would choose the other precision is a topology change: `anUpdateThatChoosesTheOtherPrecisionIsATopologyChange()` (generation 2, CLICK-1 passes).
  - **Stress.** `lp-10Hz-192k-order8` is within −144.50 dB of the double recurrence. The gain is spread: the peak response up to any section is within 0.30 dB of 0 dB.
  - **A benchmark is recorded.** None for the measurement (finding 1). The double kernel itself is benchmarked by WP-211, in `DoubleBiquadKernelTests/aBenchmarkIsRecorded()`; that was read, not run.
