## Lens checklist (§11.5)

- **A — API, architecture, platform.**

- Shape: a caseless `public enum StageValidation` of static functions that take the `LoweringContext` and return the value they checked, with typed throws of `DSPError.invalidParameter(stage:parameter:reason:)`: `frequency`, `band`, `transformLength`, `hop`, `value(_:named:in:context:)`, `value(_:named:atLeast:context:)`, `finite`. They cover the three kinds §5.11.4 lists (a frequency against Nyquist, a length against the rule, a value against a range). No state, no configuration object; every function is documented, and the type states the context (control, pure).
- The test stages reach it from outside the core (`TestCookbookLowPass` in the test target).
