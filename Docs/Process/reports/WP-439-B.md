## Lens checklist (§11.5)

- **R — real-time safety and performance.**
  - **BG-1.** `analysis(sampleRate:)` runs its work in `BackgroundWork.run` (`SystemAnalysis.swift:443–444`). That is a concurrent queue of its own at utility quality of service (`ZTronDSPCore/Background/BackgroundWork.swift:18`). It is never the main thread, the I/O thread or the analysis thread.
  - **BG-3.**
    - The work checks between its steps (`SystemAnalysis.swift:374, 390, 405, 408`), and inside the round-off figure every 16 blocks (around line 490).
    - `withTaskCancellationHandler` sets the flag.
    - A cancelled call throws `DSPError.cancelled`; one already cancelled does not start.
  - **RT rules.** The package adds no code to the audio or the analysis thread, and nothing of it runs in a plan.
  - **Complexity (§7.2, row 12).** Root finding is O(n³) and capped at degree 512. An FIR system above 513 taps is `unsupportedConfiguration` (CR-018 item 8). Uncancelled, the probe's degree-512 analysis took 18.3 s in Debug and 8.6 s in Release (indicative).
  - **Step 1 of the analysis, the roots, has no checkpoint inside** (`SystemAnalysis.swift:364–373`). Cancelled 2 ms in, the degree-512 analysis ends 12.7 s after the cancel in Debug and 0.093 s in Release (finding 2).
  - **A benchmark is recorded.** None (finding 1).
